# Vice City — موقع ومتجر السيرفر

## التشغيل
1. ثبّت Node.js (الإصدار 18 أو أحدث) من nodejs.org
2. افتح الطرفية داخل هذا المجلد ثم شغّل:

    node server.js

3. أول مرة سيطبع لك اسم المستخدم `owner` وكلمة مرور عشوائية للمالك (احفظها). 
   أو حدّدها بنفسك: `OWNER_PASSWORD=كلمتك node server.js` (على ويندوز: `set OWNER_PASSWORD=كلمتك` ثم `node server.js`)
4. الموقع: http://localhost:3000 — لوحة التحكم: http://localhost:3000/admin
   (للمنفذ: `PORT=8080 node server.js`)

لا يحتاج أي مكتبات ولا `npm install`.

## لوحة التحكم
- **المنتجات**: إضافة / تعديل / حذف، رفع صورة (سحب وإفلات) أو رابط، اسم، شرح، سعر، قسم، إظهار/إخفاء، تمييز.
- **الطلبات**: تصل من المتجر؛ غيّر حالتها (جديد / قيد المعالجة / مكتمل / ملغي) أو احذفها.
- **المستخدمون**: المالك ينشئ حسابات أدمن ويحدد صلاحية كل واحد: المنتجات، الطلبات، المستخدمون، إعدادات الموقع. يمكن إيقاف أي حساب أو تغيير كلمة مروره.
- **إعدادات الموقع**: الاسم، الشعار النصي، النبذة، رابط الديسكورد، عنوان الاتصال، الإحصائيات، ملاحظة الطلب.
- **حسابي**: تغيير كلمة المرور. غيّر كلمة مرور المالك فوراً.

## تعديل القوانين
القوانين في الملف `public/rules.json` (الأقسام: basic, general, crime, police, gangs). عدّلها وأعد تحميل الصفحة.

## الملفات
- `server.js` الخادم والـ API (حسابات مشفّرة بـ scrypt، جلسات، صلاحيات)
- `data/db.json` كل البيانات (انسخه للنسخ الاحتياطي)
- `public/` الواجهة: `index.html` `app.js` (الموقع) و `admin.html` `admin.js` (اللوحة) و `style.css` `fx.js` (التصميم والتأثيرات)

## للنشر على الإنترنت
شغّله خلف HTTPS (مثل Nginx أو Cloudflare) مع تمرير `X-Forwarded-Proto: https` ليتفعّل وسم Secure على الكوكي. الدفع غير مدمج: الطلب يصل للوحة ثم تتواصل الإدارة مع العميل عبر الديسكورد.
